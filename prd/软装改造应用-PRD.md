## 一、产品概述

### 1.1 背景

老房租房者与毛坯房住户普遍面临「软装怎么搭、搭出来好不好看、去哪买」的困扰。传统方式是逛电商自己拼，成本高、效果不可预知。本产品用「拍一张照片 → AI 生成同角度软装效果图 → 图内商品直接购买」的方式，把「想象」变成「看得见、买得到」的可视化方案。

### 1.2 产品定位（一句话）

**拍照上传房间 → 筛选风格 → 挑选软装元素 → 生成与原图同角度的软装改造效果图 → 点击图内商品经淘宝客链接跳转淘宝下单。**

### 1.3 成功标准

**购买转化率**：效果图商品点击 → 淘宝成交的转化率。

## 二、目标用户与使用场景

| 项 | 说明 |
|---|---|
| 目标用户 | 老房租房者、毛坯房住户、有软装改造需求的 C 端用户 |
| 核心场景 | 用户拿到一间空房/旧房，想知道「软装后长什么样」，并直接买齐图里的家具软装 |
| 使用频率 | ⚠️ 待确认（低频改造型，推测非高频日常） |

## 三、核心闭环（用户旅程）

一次完整交付共 5 步：

```
① 拍一张房间图片并上传
        ↓
② 筛选对应的软装风格（北欧风 / 日式原木 / 现代简约 / 轻奢…）
        ↓
③ 在该风格下挑选软装元素
   （床、床品三件套、桌子、椅子、窗帘、地板、地毯等）
        ↓
④ 生成一张与原图「同角度」的软装改造效果图
        ↓
⑤ 点击效果图中的商品，经淘宝客推广链接跳转淘宝下单
```

**交付物**：一张与原图同角度的软装改造效果图 + 图内商品可点击跳转淘宝购买。

## 四、功能需求

### F1 照片上传
- 用户拍摄或选择一张房间照片上传；
- 照片作为出图输入，**仅在本次会话内暂存，不落库、不外传**；
- 上传需用户授权（隐私数据，权限 = ask）。

### F2 风格筛选
- 上传后可筛选软装风格（如北欧风、日式原木、现代简约、轻奢）；
- 风格列表为只读查询。

### F3 软装元素挑选
- 每个风格下展示对应软装元素清单（床、床品三件套、桌子、椅子、窗帘、地板、地毯等）；
- 用户从中挑选要搭配的元素（多选）。

### F4 同角度效果图生成
- 基于原图 + 已选风格 + 已选元素，生成**一张与原图同角度**的软装改造效果图；
- **只做同角度**，不做另一角度、不做俯视（鸟瞰）图；
- 通过**图像编辑/重绘模型**实现（对原图做编辑，天然保持同角度），不采用文生图；
- 属**消耗型操作**（计费），需用户确认（权限 = ask），并受单次成本上限约束。

### F5 商品点击购买
- 效果图中的软装元素对应淘宝商品，用户点击后经**淘宝客推广链接**跳转淘宝下单；
- 本应用**不代下单、不代支付、不沉淀资金**，只做跳转；
- 商品、价格、链接一律以淘宝客 API 返回为准，查不到时明示「暂无对应商品」，禁止编造。

### F6 转化追踪
- 上报效果图内商品点击事件（带 out_click_id）；
- 通过淘宝客订单回传/效果报表 API 对齐成交，计算购买转化率。

## 五、外部依赖与接口

### 5.1 淘宝客（淘宝联盟）— 账号已注册
| 用途 | 说明 |
|---|---|
| 商品映射 | 淘宝客**选品库 API**：软装元素 → 淘宝商品 |
| 推广链接 | 淘宝客**推广链接 API**：生成带推广位（PID）的跳转链接 |
| 转化归因 | 淘宝客**订单回传/效果报表 API**：点击与成交对齐 |

### 5.2 图像生成（蚂蚁 MaaS 平台）
| 用途 | 说明 |
|---|---|
| 出图 | 通过 `maas.antdigital.com` 的图像编辑 API 生成同角度效果图 |
| 模型 | 具体模型为**配置项**（`IMAGE_MODEL_ID`），不硬编码，可替换 |

### 5.3 主模型（LLM）
- 用于自然语言驱动的 agent 决策（`/chat` 入口）；
- 通过 Anthropic 兼容网关接入，`MODEL_ID` 为配置项。

## 六、非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 出图时延、并发量、单次生成成本上限 ⚠️ 具体数值待确认 |
| 安全 | 资金动作一律拒绝；照片敏感处理不落库；成本上限未配置时拒绝出图；不合规推广拒绝 |
| 合规 | 淘宝客推广链接生成与投放需符合淘宝客/联盟推广规范 |
| 可运行 | 单进程服务 + 一条命令启动；密钥全部外置 `.env`（只提交 `.env.example`） |
| 可观测 | 日志、指标（转化率/出图成功率/成本）、轨迹数据 |
| 可测试 | 工具单测 + 权限/安全边界测试 |

---

## 七、权限与安全边界

| 规则 | 处理 |
|---|---|
| 代下单 / 代支付 / 沉淀资金 | **deny**（一律拒绝，只跳转淘宝） |
| 照片用于出图之外用途 | **deny**（仅本次出图使用，不落库、不外传） |
| 成本上限未配置或超限 | **deny** 出图调用 |
| 不合规推广 | **deny** 链接生成 |
| 商品 / 价格 / 链接编造 | 禁止，只透出淘宝客 API 真实返回 |

## 八、成功指标（可度量）

| 指标 | 说明 |
|---|---|
| **购买转化率** | 效果图商品点击 → 淘宝成交（核心成功标准） |
| 出图成功率 | 生成请求 → 通过交付的数量（含超时率） |
| 单次出图成本 | 模型成本选型依据 |
| 各步骤转化漏斗 | 上传 → 选风格 → 选元素 → 出图 → 点击商品 |

## 九、待确认项（非阻塞，可边做边定）

1. 目标用户画像与使用频率；
2. 同步 / 异步交互方式；
3. 时延、并发量、单次生成成本上限的具体数值；
4. 房间照片的存储位置与保留期限（当前默认「不留存」）；
5. 风格库与软装元素库的数据来源与维护方式；
6. 图像模型在 MaaS 平台上的具体选型（配置项，接 API 时确定）。
