# 好搭 · 前端

Next.js 网页提供软装风格展示、家具选款、图片前后对比及商品对应链接。

## 页面

- `/`：宣传首页、风格和固定改造案例。
- `/design`：左侧上传与筛选，右侧原图、生成结果对比和选购入口。
- `/r/{taskId}`：根据任务编号恢复结果或查看失败诊断。

家具图库是 AI 款式示意，不是真实在售 SKU；购买入口为淘宝相似款搜索，无佣金或转化追踪。“登录”尚未接账号系统，不能当作权限保护。

## 本地开发

需要 Node.js 22.12+ 和 npm。先启动同仓库 `../backend/`，再在本目录执行：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:3000/ 。同源 `/api/v1/*` 默认代理至 `http://127.0.0.1:8000`。

自定义地址只在前端 `.env.local` 设置 `BACKEND_URL`，不要填写模型密钥。生产代理地址在构建时确定，修改后需重新构建。

## 不调用模型的演示

```sh
npm run build:demo
npm run serve:demo
```

打开 http://127.0.0.1:3101/ 。演示只包含公开素材、筛选、固定前后对比和相似款搜索；选款不改变示例图，不上传照片或调用模型。

导出构建使用源码白名单，不读取后端数据或 `.env`。静态服务拒绝写请求、API、历史结果和隐藏文件访问。对外演示时只暴露这个静态服务，不要把带真实密钥的 3000/8000 服务直接开放公网。

## 检查与构建

```sh
npm run test
npm run lint
npm run build
npm run typecheck
```

生产模式本地查看：构建结束后运行 `npm run start`。不要在生产服务运行时重建，以免旧页面引用已替换的脚本；先停止旧服务再构建、重启。

服务运行时可执行 `npm run check:assets` 核对页面引用的脚本、样式、字体和图片响应，不会创建模型生成任务。

`scripts/browser-smoke.mjs` 是早期页面的浏览器辅助检查脚本，未随当前工作台全面更新，不作为当前 E2E 已通过的证明；其输出保存在被忽略的 `test-results/`。

## 照片与任务

选照片只在本机预览，点击“上传这张照片”后才发给后端。确认生成后，原图和商品图将发送至确认框显示的模型提供方；不要假定一定只在国内处理。

原图不放入浏览器持久存储、URL 或日志。任务结果与选款由后端保存；页面轮询失败时保留任务入口，不自动重复付费提交。

前后端源码、图片和字体应保持同仓库目录关系；后端需要读取前端的版本化家具目录和素材。安全限制见 [安全说明](../SECURITY.md)。
