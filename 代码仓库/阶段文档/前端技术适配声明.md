- 主要终端：桌面 Web 与移动 Web，移动端需支持直接从相册选择或拍摄房间照片。

## 3. 技术选择

- 框架与版本：Next.js 16.3.5、React 19.3.0、TypeScript strict；版本在创建工程时锁入 `package-lock.json`。
- 样式与组件：Tailwind CSS 4.3.3 + CSS 语义变量；原生语义组件。本次按参考移除页面装饰图标，使用文字链接、字形箭头和直角边框，不引入整套 UI 库。
- 构建与检查：开发及构建使用 Webpack；ESLint 9.39.5 与 Next 配置兼容，未通过禁用规则绕过检查。
- 数据请求：统一放在 `lib/api/` 与 `features/renovation/api/`，页面组件不直接拼接请求地址。
- 状态策略：React 局部状态 + URL 中的任务 ID；当前只有一个核心工作流，不引入 TanStack Query、Zustand 或 Redux。
- 接口校验：为风格、元素、任务和商品响应编写严格 TypeScript 类型与运行时保护；未知状态进入安全兜底，不当作成功。
- 通信策略：后端异步受理任务，前端轮询 `GET /tasks/{id}`；不引入 SSE/WebSocket。真实状态以后端为准，不显示虚假百分比。
- 表单策略：上传与多选交互较简单，使用受控组件和轻量校验，不引入复杂表单库。
- 测试方案：Vitest 5.0.1 + React Testing Library；同时执行 Lint、TypeScript 和生产构建。浏览器真实闭环与响应式截图仍待验，当前工具拒绝操作该地址，不将单元测试当作浏览器验收。
- 后端连接：开发与部署均由 Next.js 同源代理 `/api/*` 到 FastAPI，服务端地址只放在 `BACKEND_URL`，不把模型密钥或后端私密配置暴露给浏览器。

## 4. 任务状态与恢复

| 后端或交互状态 | 前端统一状态 | 用户看到的内容 |
| --- | --- | --- |
| 尚未上传 | `idle` | 上传房间照片和格式说明 |
| 上传请求中 | `submitting` | 上传进度提示，禁止重复上传 |
| 已上传、配置未完成 | `idle` | 风格和元素选择 |
| 点击生成前 | `waiting_user` | 预计单次成本约 ¥0.30、已选风格与元素、取消和确认按钮 |
| `/tasks` 请求未返回 | `running` | AI 正在保持原角度改造，停止重复提交，可离开但不能承诺后台继续 |
| 后端返回 `succeeded` | `succeeded` | 效果图、下载、重新设计和商品列表 |
| 请求或任务失败 | `failed` | 普通用户可理解的原因、重试或重新上传入口 |
| 已有任务 ID 重新打开 | `loading` → `succeeded/failed` | 从后端恢复任务与效果图 |
| 未知后端状态 | `stale` | 状态可能已变化，提供重新获取入口 |

- 计费确认：生成调用前必须由用户在确认层明确点击“确认并生成”；弹层关闭或返回不会发起请求。
- 防重复：生成期间按钮禁用，并为同一次页面操作设置客户端提交锁；当前后端尚无幂等键，不能把网络超时自动重试为再次创建任务。
- 取消目标：后端没有取消接口，只能停止等待。当前按钮仍写“取消生成”，但实际只停止前端轮询，不中断模型；列入后续任务交互修复，不能当作已实现后台取消。
- 恢复：成功后将任务 ID 写入 `/r/{taskId}`，通过 `GET /api/v1/tasks/{id}` 恢复结果与已提交选款。创建接口已返回 processing 任务 ID，但前端尚未实现生成中的刷新恢复。

## 5. 页面、组件与产物

- 核心路由：`/` 为软装设计工作台；`/r/[taskId]` 为可刷新恢复的结果页。
- 核心闭环：上传照片 → 选择风格 → 按房间选择软装元素 → 确认成本 → 生成真实效果图 → 查看/下载 → 展开商品卡并跳淘宝。
- 代表页：先完成工作台的上传、风格、元素和生成确认区域，确认视觉后再实现结果页和商品区。
- 产物：JPEG 效果图，保留原始比例；提供加载占位、失败提示、放大查看和下载。
- 响应式目标：检查 390px、768px、1280px、1440px；触控目标不小于 44px，页面无整体横向滚动；风格目录内部允许横向滚动。

## 6. 推荐视觉方向

- 定位：像一本克制的居家设计刊物，让暖光室内摄影成为页面主角。
- 色彩：纸色 `#fafaf9`、亚麻色 `#f8f7f1`、酒红墨色 `#4a0a05`；石色 `#bcb6a6` 用于次级边框，陶土灰 `#a2827f` 仅作次要图注。
- 字体：使用参考允许的免费替代 Inter / Cormorant Garamond；中文配 Noto Sans SC / Noto Serif SC。400 字重、24–26px 标题；字体和许可证本地托管，不引入商业字体。
- 形态：照片、卡片、按钮、弹层均直角，无投影，无彩色实心按钮；以细线和文字表达交互状态。
- 结构：全幅主视觉 → 编辑手记 → 工作台（上传与原图预览 → 风格 → 房间与家具 → 搭配清单）→ 拍照指南 → 多栏文字页脚；中古风置首但不默认替用户选中；小屏上传与原图预览单列。
- 动效：横向平滑滚动和轻微图片缩放；开启“减少动态效果”后停止这些动效。
- 图片：内置 imagegen 生成一张主视觉和五张风格意向图，明确标注 AI 创作，仅作界面素材，不作为真实模型冒烟结果。
- 09-19 风格修正：五张风格图更新为 v3，分别以胡桃木皮革、浅木灰白、低矮原木与障子、奶白曲面、石膏线雕花家具区分。未选照片时原图区显示真实空态，不复用主视觉冒充用户空间。

## 7. 与默认手册的偏离

- 不引入服务端状态库：当前只有一条单页核心流程，React 局部状态和 URL 已足够。
- 不实现 SSE 和任务中心；当前单流程已使用异步任务与轮询。
- 生成中的刷新恢复尚未实现；后端已返回任务 ID，但前端仍待补完整恢复交互。
- MVP 不做登录：沿用已确认的阶段决策；正式上线前必须补邀请码登录与后端数据隔离。
- 商品暂为静态淘宝搜索链接：界面明确标注“跳转淘宝搜索，暂无佣金”，不展示虚构价格或商品图片。
